# Learn programming by making things.

EduPython Kids is an open beginner programming course for children around ages 9–12, with age 10 as the primary target.

Start by making something work. Change it. Predict what will happen. Run it again. Learn why it works as you go.

## Start here

### 🇳🇴 Norsk

**Elev:** Start med [Python Explorer på norsk](course/no/README.md). Kurset har 16 leksjoner fra første `print()` til et selvstendig sluttprosjekt. Etterpå kan du fortsette rett videre til **Python Game Maker** i samme kursindeks og bygge ditt eget lille Turtle-spill. Bruk også [øvelsene](exercises/no/README.md) og [elevsjekklisten](course/no/ELEV-SJEKKLISTE.md).

**Lærer eller forelder:** Start med [lærer- og foreldreguiden](teacher-guide/README.md). Se også [pacing](teacher-guide/PACING.md), [løsningsnotater](teacher-guide/solutions/README.md), [prosjektrubrikk](teacher-guide/PROJECT-RUBRIC.md) og [tilgjengelighet](docs/no/ACCESSIBILITY.md).

### 🇬🇧 English

**Student:** Start with [Python Explorer in English](course/en/README.md). It is a complete 16-lesson first-class course edition. Then continue directly to **Python Game Maker** in the same course index and build your own small Turtle game. Use the [English exercises](exercises/en/README.md) and [student checklist](course/en/STUDENT-CHECKLIST.md) too.

**Teacher or parent:** Start with the [English teacher/parent guide](teacher-guide/en/README.md). See also [pacing](teacher-guide/en/PACING.md), [solution notes](teacher-guide/en/solutions/README.md), [project rubric](teacher-guide/en/PROJECT-RUBRIC.md) and [accessibility guidance](docs/en/ACCESSIBILITY.md).

Norwegian is the primary authoring language. Norwegian and English are equal first-class supported editions; see the [language parity policy](docs/LANGUAGE-PARITY.md).

## 🎮 Python Game Maker

Game Maker adds 10 short missions after Python Explorer: move, stay on screen, catch a target, score points, escape a monster, use lives, add feedback, assemble a mini-game and finally make your own game.

The content is complete in Norwegian and English. M3 is **not yet qualified**: its documented Turtle/Tk desktop test still has to pass on a real graphical environment. See [M3 qualification](docs/M3-QUALIFICATION.md).

## 🖨 Print and offline

Use the [Norwegian and English printable sheets](printable/README.md) with the canonical lessons.

For offline teaching, see the [English offline guide](docs/OFFLINE.md) or [Norwegian offline guide](docs/no/OFFLINE.md). The generated offline bundle contains both course editions and supporting material.

## Course path

| Stage | Lessons | Focus |
| --- | --- | --- |
| Oppdag / Discover | 1–4 | output, variables, input, numbers |
| Velg / Decide | 5–8 | conditions, randomness, loops, first game |
| Bygg / Build | 9–12 | while, game state, functions, Monster Battle |
| Skap / Create | 13–16 | lists, Turtle, decomposition, final project |

## What you need

Python 3.11 or newer is recommended. See the [English installation guide](docs/INSTALL.md) or [Norwegian installation guide](docs/no/INSTALL.md).

The core course requires no student account, cloud service or proprietary learning platform. Once Python and the material are installed, the course can be used offline. Turtle lessons require local Tk/Turtle support.

## Project status

M0 Foundation and M1 Python Explorer are qualified. Course 1 Norwegian/English language parity is qualified with continuous human review.

M2 Classroom Quality is complete on the repository and Pages side but remains deliberately open until the documented Turtle/Tk Q1–Q6 procedure passes on a real graphical desktop environment.

M3 Python Game Maker is content complete in both languages and remains deliberately open until its documented Turtle/Tk Q1–Q9 desktop qualification passes.
