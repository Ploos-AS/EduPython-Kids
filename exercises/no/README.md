## Symboler

- **A, B, C ...** – vanlige øvelser
- **Forutsi først / Tenk** – stopp og tenk før programmet kjøres
- **🐞 Bug-jakt** – finn eller forstå en feil
- **⭐ Bonus** – frivillig ekstrautfordring
- **🌟 Ekstra / Designutfordring** – mer åpent arbeid

Det viktigste er å eksperimentere og kunne forklare hva du endret.
