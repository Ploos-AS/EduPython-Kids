# Øvelser 11 – Funksjoner

## A – Egen hilsen

Lag funksjonen `hils(navn)` som skriver en hilsen.

Kall den med minst tre forskjellige navn eller oppdiktede figurer.

## B – Regnemaskin

Lag:

```python
def dobbel(tall):
    ...
```

og

```python
def trippel(tall):
    ...
```

Begge skal sende svaret tilbake med `return`.

## C – Terningfunksjon

Lag `kast_terning()` som returnerer et tilfeldig tall fra 1 til 6.

Bruk funksjonen fem ganger.

## D – Forutsi først

Hva skriver dette?

```python
def pluss_en(tall):
    return tall + 1

svar = pluss_en(4)
print(svar)
```

## ⭐ Bonus

Lag `kast(sider)`, slik at samme funksjon kan brukes som d6, d10 eller d20.
