# Exercises 03 – Talk to the computer

These are optional extra exercises. You do not need to complete everything.

## A – Three questions

Ask three questions about a fictional character and print a short introduction.

## B – Change the prompt

Rewrite one question and check that the answer is still used correctly.

## C – Predict first

Where is the value returned by `input()` stored?

## ⭐ Bonus

Make the final introduction use all three answers.
