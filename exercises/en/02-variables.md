# Exercises 02 – The program remembers

These are optional extra exercises. You do not need to complete everything.

## A – Character card

Create variables for a fictional character's name, age, favourite food and score.

## B – Change a value

Print a score, give it a new value, and print it again.

## C – Predict first

What will happen if you use a variable before giving it a value?

## ⭐ Bonus

Add two more facts and print a complete character card.
