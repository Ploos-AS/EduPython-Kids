## Symbols

- **A, B, C ...** – regular exercises
- **Predict first / Think** – stop and predict before running
- **🐞 Bug hunt** – find or understand an error
- **⭐ Bonus** – optional extra challenge

The important part is experimenting and being able to explain what you changed.
