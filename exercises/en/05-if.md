# Exercises 05 – The program chooses with if

These are optional extra exercises. You do not need to complete everything.

## A – Guard robot

Ask for a fictional secret word. Print one reply if it matches and another if it does not.

## B – Fantasy temperature

Use a `temperature` variable and choose between frozen and not frozen.

## C – Predict first

With `score = 7`, what does `if score > 5` do? What changes at 5?

## ⭐ Bonus

Create three paths using `if`, `elif` and `else`.
