# Exercises 11 – Functions

These are optional extra exercises. You do not need to complete everything.

## A – Reusable greeting

Create a function with one parameter and call it with different values.

## B – Return a value

Create `triple(number)` and use its returned result in another calculation.

## C – Bug hunt

Remove the colon after `def`. Read the error and repair it.

## ⭐ Bonus

Create `roll_die()` that returns a random number.
