# Exercises 09 – Keep going with while

These are optional extra exercises. You do not need to complete everything.

## A – Code word loop

Keep asking for a fictional code word until it is correct.

## B – Countdown

Count from 10 down to 1.

## C – Bug hunt

Make a loop that forgets to change its counter. Why does it not stop?

## ⭐ Bonus

Create another loop that ends because a value changes.
