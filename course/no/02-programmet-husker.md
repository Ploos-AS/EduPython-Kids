# 2 — Programmet husker

## 🎯 Oppdrag

Få programmet til å huske navnet ditt.

```python
navn = "Ada"

print("Hei", navn)
```

Bytt `Ada` med navnet ditt og kjør programmet.

## 🧠 Hva skjedde?

`navn` er en **variabel**.

Du kan tenke på en variabel som en liten boks med en merkelapp:

```text
navn  ->  "Ada"
```

Når Python ser `navn`, kan den bruke det som ligger i boksen.

## 🔧 Endre

Lag flere bokser:

```python
navn = "Ada"
alder = 10
favoritt = "pizza"

print("Jeg heter", navn)
print("Jeg er", alder, "år")
print("Jeg liker", favoritt)
```

Endre verdiene så programmet beskriver deg.

## 🤔 Tenk

Hva tror du dette programmet skriver ut?

```python
poeng = 5
print(poeng)

poeng = 8
print(poeng)
```

Prøv det.

En variabel kan få en ny verdi. Programmet husker den nyeste verdien.

## ⭐ Utfordring

Lag et lite spillerkort med minst fire variabler:

- spillerens navn
- alder
- favorittdyr
- antall poeng

Skriv alt ut med `print()`.

## 🐛 Bug-jakt

Hva er galt her?

```python
navn = "Linus"
print(Navn)
```

Hint: Python ser forskjell på store og små bokstaver.

## 🧠 Det du lærte

- En variabel kan lagre en verdi.
- `=` gir en variabel en verdi.
- Variabler kan inneholde tekst og tall.
- Verdien kan endres underveis.
- Python skiller mellom store og små bokstaver.
