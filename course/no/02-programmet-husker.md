# 02 – Programmet husker

## 🎯 Oppdrag

Få programmet til å huske navnet på en figur.

## 💻 Kode

```python
navn = "Ada"

print("Hei", navn)
```

Bytt `Ada` med et navn du velger og kjør programmet.

## 🧠 Hva skjedde?

`navn` er en **variabel**.

Du kan tenke på en variabel som en liten boks med en merkelapp:

```text
navn  ->  "Ada"
```

Når Python ser `navn`, kan programmet bruke verdien som ligger der.

## 🔧 Endre

Lag flere variabler:

```python
navn = "Ada"
alder = 10
favoritt = "pizza"

print("Figuren heter", navn)
print("Figuren er", alder, "år")
print("Figuren liker", favoritt)
```

Endre verdiene og lag din egen figur.

## 🤔 Tenk

Hva tror du dette programmet skriver ut?

```python
poeng = 5
print(poeng)

poeng = 8
print(poeng)
```

Prøv det.

En variabel kan få en ny verdi. Programmet bruker den nyeste verdien.

## ⭐ Utfordring

Lag et lite spillerkort med minst fire variabler, for eksempel:

- spillerens navn
- alder
- favorittdyr
- antall poeng

Skriv alt ut med `print()`.

Se [ekstra øvelser](../../exercises/no/02-programmet-husker.md) når du vil prøve mer.

## 🐞 Bug-jakt

Hva er galt her?

```python
navn = "Linus"
print(Navn)
```

Hint: Python ser forskjell på store og små bokstaver.

## 🧠 Det du lærte

- En variabel kan lagre en verdi.
- `=` gir en variabel en verdi.
- Variabler kan inneholde tekst og tall.
- Verdien kan endres underveis.
- Python skiller mellom store og små bokstaver.
