# 01 – Hei, Python!

## 🎯 Oppdrag

Få datamaskinen til å skrive noe du har bestemt.

## 💻 Kode

```python
print("Hei!")
print("Jeg programmerer i Python!")
```

## ▶ Kjør

Lagre programmet som `hei.py` og kjør det:

```bash
python hei.py
```

Du har nettopp laget et program.

## 🔧 Endre

Bytt ut teksten med noe du vil at programmet skal skrive.

Prøv for eksempel:

```python
print("Jeg liker pannekaker!")
```

Du kan skrive nesten hva du vil mellom anførselstegnene.

## 🤔 Tenk

Hva tror du skjer hvis du har tre `print()`-linjer?

Prøv før du leser videre.

Hver `print()` skriver noe på skjermen. Med tre linjer får du tre utskrifter.

## ⭐ Utfordring

Lag et program som skriver tre ting om en oppdiktet figur, for eksempel:

1. navnet
2. noe figuren liker
3. noe morsomt figuren sier

Du kan også bruke informasjon om deg selv hvis du vil.

Se [ekstra øvelser](../../exercises/no/01-hei-python.md) når du vil prøve mer.

## 🐞 Bug-jakt

Denne koden virker ikke:

```python
print("Hei!)
```

Kan du finne feilen?

Hint: Se nøye på anførselstegnene.

## 🧠 Det du lærte

- Et program er instruksjoner datamaskinen følger.
- `print()` skriver tekst på skjermen.
- Tekst i Python står ofte mellom anførselstegn.
- Feil er en vanlig del av programmering.
