# 1 — Hei, Python!

## 🎯 Oppdrag

Få datamaskinen til å si noe du har bestemt.

Skriv dette i en fil som heter `hei.py`:

```python
print("Hei!")
print("Jeg programmerer i Python!")
```

## ▶ Kjør

Kjør programmet:

```bash
python hei.py
```

Du har nettopp laget et program.

## 🔧 Endre

Bytt ut teksten med noe du vil at maskinen skal si.

Prøv for eksempel:

```python
print("Jeg liker pannekaker!")
```

Du kan skrive nesten hva du vil mellom anførselstegnene.

## 🤔 Tenk

Hva tror du skjer hvis du har tre `print()`-linjer?

Prøv før du leser videre.

Hver `print()` skriver noe ut på skjermen. Med tre linjer får du tre utskrifter.

## ⭐ Utfordring

Lag et program som skriver:

1. navnet ditt
2. noe du liker
3. noe morsomt

## 🐛 Bug-jakt

Denne koden virker ikke:

```python
print("Hei!)
```

Kan du finne feilen?

Hint: Se nøye på anførselstegnene.

## 🧠 Det du lærte

- Et program er instruksjoner datamaskinen følger.
- `print()` skriver tekst på skjermen.
- Tekst i Python står ofte mellom anførselstegn.
- Feil er en vanlig del av programmering.
