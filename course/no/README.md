# Python Explorer – elevkurs

Velkommen! Dette kurset er laget for barn rundt 9–12 år. Du trenger ikke kunne programmere fra før.

## Slik jobber du

Hver leksjon har et oppdrag, litt kode du kan kjøre, ting du kan endre, spørsmål du kan tenke på og en utfordring. Det er lov å prøve noe som ikke virker. Feil er spor som hjelper deg videre.

## Husk

Du trenger ikke huske all Python-kode utenat. Programmerere slår opp ting, tester ideer og retter feil hele tiden.

Målet er at du etter kurset kan få en idé til et lite program og finne ut hvordan du kan bygge det.
