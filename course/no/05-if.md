# 05 – Programmet velger med if

## 🎯 Oppdrag

Lag en liten dørvakt som reagerer på et hemmelig ord.

## 💻 Kode

```python
ordet = input("Hva er det hemmelige ordet? ")

if ordet == "python":
    print("Døren åpner seg!")
else:
    print("Døren er fortsatt låst.")
```

Legg merke til kolon `:` og innrykket foran `print()`.

## 🔧 Endre

Finn på ditt eget hemmelige ord og egne svar.

## 🤔 Tenk

Hva tror du `==` betyr? Det spør om to ting er like. Det er forskjellig fra `=`, som brukes når vi lagrer en verdi.

## ⭐ Utfordring

Spør også etter alder. La programmet gi forskjellige svar avhengig av tallet.
