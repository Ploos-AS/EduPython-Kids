# Min Python-sjekkliste

Kryss av når du føler at du kan gjøre dette. Du trenger ikke kunne alt utenat.

- [ ] Jeg kan kjøre et Python-program.
- [ ] Jeg kan bruke `print()`.
- [ ] Jeg kan lagre noe i en variabel.
- [ ] Jeg kan spørre brukeren med `input()`.
- [ ] Jeg kan bruke Python til enkel regning.
- [ ] Jeg kan lage et valg med `if`.
- [ ] Jeg kan bruke tilfeldige tall.
- [ ] Jeg kan gjenta kode med `for`.
- [ ] Jeg kan gjenta kode med `while`.
- [ ] Jeg kan lage en funksjon.
- [ ] Jeg kan bruke en liste.
- [ ] Jeg kan tegne noe med Turtle.
- [ ] Jeg kan lese en enkel feilmelding og lete etter feilen.
- [ ] Jeg kan endre et eksisterende program og gjøre det mer mitt.
- [ ] Jeg kan lage et lite program fra min egen idé.

## Det viktigste

Jeg vet at kode ikke trenger å virke på første forsøk.

**Programmering er å prøve, undersøke og forbedre.**
