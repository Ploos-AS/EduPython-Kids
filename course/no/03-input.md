# 03 – Snakk med datamaskinen

## 🎯 Oppdrag

Lag et program som spør hva du heter og svarer deg.

## 💻 Kode

```python
navn = input("Hva heter du? ")
print("Hei", navn + "!")
```

## ▶ Kjør

Lagre programmet og kjør det. Skriv navnet ditt når Python spør.

## 🔧 Endre

Bytt spørsmålet til noe annet, for eksempel favorittdyr:

```python
dyr = input("Hva er favorittdyret ditt? ")
print("Kult! Jeg liker også", dyr)
```

## 🤔 Tenk

Hva tror du `input()` gjør? Hvor blir svaret lagret?

## ⭐ Utfordring

Få programmet til å stille tre spørsmål og skrive en liten presentasjon til slutt.
