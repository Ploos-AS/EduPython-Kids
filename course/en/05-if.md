# 05 – The program chooses with if

## 🎯 Mission

Make a little door guard that chooses between two answers.

## 💻 Code

```python
word = input("What is the secret word? ")

if word == "python":
    print("The door opens!")
else:
    print("The door is still locked.")
```

A **condition** is a question that can be true or false. Here the program asks whether `word` is equal to `"python"`.

Notice the colon `:` and the indentation before `print()`.

## 🤔 Think

What do you think `==` means?

`==` asks whether two values are equal. It is different from `=`, which gives a variable a value.

## 🧠 What you learned

- `if` lets the program choose code when a condition is true.
- `else` provides another path.
- `==` compares values.
- `=` stores a value.
- Colons and indentation matter in Python.
