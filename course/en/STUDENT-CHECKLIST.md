# My Python checklist

Tick a box when you feel you can do it. You do not need to remember everything.

- [ ] I can run a Python program.
- [ ] I can use `print()`.
- [ ] I can store something in a variable.
- [ ] I can ask the user something with `input()`.
- [ ] I can use Python for simple arithmetic.
- [ ] I can make a choice with `if`.
- [ ] I can use random numbers.
- [ ] I can repeat code with `for`.
- [ ] I can repeat code with `while`.
- [ ] I can create a function.
- [ ] I can use a list.
- [ ] I can draw something with Turtle.
- [ ] I can read a simple error message and look for the problem.
- [ ] I can change an existing program and make it more my own.
- [ ] I can make a small program from my own idea.

## The most important thing

I know that code does not need to work on the first try.

**Programming means trying, investigating and improving.**
