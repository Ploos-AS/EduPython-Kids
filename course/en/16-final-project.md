# 16 – Final project: Make something of your own

## 🎯 Mission
Create a small Python project that you decide. You might make a text adventure, quiz, guessing or dice game, Turtle drawing, monster game, random story generator, or your own idea.

## 📝 1 – Plan
Answer in one sentence each: What should the program do? What should the player or user be able to do? Which Python tools do you think you need? You may change the plan later.

## 🧩 2 – Make the smallest version first
Ask: **What is the smallest version that shows my idea?** Get that working first, then add one improvement at a time.

## 🧪 3 – Test and improve
Test at least three times. Read errors, find the indicated line, check punctuation and indentation, inspect variables when useful, change one thing, and run again.

## ⭐ 4 – Make the project yours
Choose at least three improvements: your own theme, more choices, score, randomness, more rounds, functions, a list, graphics, a surprise, or something no exercise asked for.

## 🎤 5 – Show it
Demonstrate the project. Explain your idea, how it is used, a part you like, a bug or surprise you found, something you changed after testing, and what you would build next.

## 🤔 Think back
Find something from an earlier lesson in your project and explain why the code works. Understanding matters more than memorising syntax.

## 🏁 Finished?
The project does not need to be perfect. If you made an idea work, tested it, found problems and improved it, you have practised the complete workflow.

## 🧠 What you practised
- `print()`, `input()`, variables and arithmetic
- `if`, `elif`, `else`
- randomness
- `for` and `while`
- functions, parameters and `return`
- lists
- Turtle graphics
- testing and debugging
