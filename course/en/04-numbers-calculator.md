# 04 – Numbers and mini calculator

## 🎯 Mission

Build a calculator that adds two numbers.

## 💻 Code

```python
a = int(input("First number: "))
b = int(input("Second number: "))

answer = a + b
print("The answer is", answer)
```

`input()` gives us text. `int()` can turn text such as `"12"` into the whole number `12`.

## 🔧 Change

Try subtraction and multiplication.

## 🤔 Think

What do you think happens if you enter a word when `int()` expects a number?

The error message is a clue.

## 🧠 What you learned

- Python can calculate with numbers.
- `input()` returns text.
- `int()` can convert suitable text to a whole number.
- Error messages can help explain what went wrong.
