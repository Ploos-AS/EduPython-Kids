# 01 – Hello, Python!

## 🎯 Mission

Make the computer display something you chose.

## 💻 Code

```python
print("Hello!")
print("I am programming in Python!")
```

## ▶ Run

Save the program as `hello.py` and run it:

```bash
python hello.py
```

You just made a program.

## 🔧 Change

Change the text. Try making the program say something funny.

## 🤔 Think

What do you think happens if you add a third `print()` line?

Predict first, then try it.

## ⭐ Challenge

Create a fictional character and print three things about them.

## 🐞 Bug hunt

What is wrong here?

```python
print("Hello!)
```

Hint: look at the quotation marks.

## 🧠 What you learned

- A program is a set of instructions.
- `print()` displays text.
- Python text is often written inside quotation marks.
- Bugs are a normal part of programming.
