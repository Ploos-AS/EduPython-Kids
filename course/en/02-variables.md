# 02 – The program remembers

## 🎯 Mission

Make the program remember information about a character.

## 💻 Code

```python
name = "Ada"
print("Hello", name)
```

`name` is a **variable**. A variable gives a value a name so the program can use it later.

## 🔧 Change

Add variables for age, favourite food and score.

## 🤔 Think

What will this print?

```python
score = 5
print(score)
score = 8
print(score)
```

Predict first, then run it.

## ⭐ Challenge

Create a character card using at least four variables.

## 🧠 What you learned

- A variable can store a value.
- `=` gives a variable a value.
- Variables can hold text and numbers.
- A variable can receive a new value later.
