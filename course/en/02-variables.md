# 02 – The program remembers

## 🎯 Mission
Make a small character card and let the program remember information about your fictional character.

## 💻 Code
```python
name = "Nova"
score = 5

print(name)
print(score)
```

A **variable** is a name we give to a value so the program can use it later.

## ▶ Run
Run the program. It should print the character name and score.

## 🔧 Change
Change the name and score. Then try changing the value again before `print()`:

```python
animal = "cat"
animal = "dog"
print(animal)
```

The program prints the newest value: `dog`.

## 🤔 Think
What do you think happens if you write `print(animal)` before the second assignment too?

## 🐞 Bug hunt
Try this:

```python
hero = "Pixel"
print(her0)
```

Read the error. Compare the variable names carefully. What is different?

## 🧠 What you learned
- A variable stores a value under a name.
- `=` assigns a value.
- A variable can receive a new value later.
- Variable names must match when you use them.
