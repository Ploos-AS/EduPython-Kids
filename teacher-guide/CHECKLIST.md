# Teacher / parent checklist

You do not need to be an experienced programmer to guide Course 1.

## Before the course

- [ ] Python 3 starts on the learner's computer.
- [ ] The learner can create, save and run a `.py` file.
- [ ] `print("Hei!")` works.
- [ ] Turtle works before lesson 14.
- [ ] Course files are available offline.
- [ ] The learner knows where their own programs are saved.

## During a lesson

- [ ] Let the learner run working code early.
- [ ] Ask what they think will happen before a change is run.
- [ ] Encourage changing names, numbers and messages.
- [ ] Let the learner read the error before giving the answer.
- [ ] Give hints before complete solutions.
- [ ] Stop while programming is still enjoyable rather than forcing a chapter to completion.

## When something breaks

Ask these questions in order:

1. What does the error say?
2. Which line does it mention?
3. What changed since the program last worked?
4. Are parentheses and quotation marks paired?
5. Is a colon missing?
6. Is indentation correct?

## Course completion

A learner does not need to memorize syntax. Course 1 is successful when the learner can experiment, debug with some guidance and create a small program of their own.


## Accessibility before class

Review [the accessibility guidance](../docs/ACCESSIBILITY.md), especially when a learner uses assistive technology, needs larger text, has difficulty typing, or when Turtle/Tk will be used.
