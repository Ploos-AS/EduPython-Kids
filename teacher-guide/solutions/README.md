## Bruk

Prøv spørsmål og små hint før du viser løsningskode. Flere løsninger kan være riktige, særlig i de senere leksjonene.

Målet er at eleven gradvis kan forklare egne valg, teste ideer og finne feil – ikke at elevens program blir identisk med eksemplet.
