# Lærernotater og løsningsforslag – leksjon 5–8

Flere løsninger kan være riktige. Målet er å hjelpe eleven til å forklare hva programmet gjør, ikke bare produsere riktig kode.

## 05 – if

**Mål:** Eleven forstår at programmet kan velge hvilken kode som skal kjøre.

Et enkelt eksempel:

```python
ord = input("Hemmelig ord: ")

if ord == "python":
    print("Du kan komme inn!")
else:
    print("Prøv igjen senere.")
```

Viktige feil å la eleven undersøke:

- `=` i stedet for `==`
- manglende kolon
- feil innrykk

Når `elif` introduseres, tegn gjerne tre veier på papir: én av dem velges.

## 06 – tilfeldighet

**Mål:** Eleven forstår at programmet kan velge en verdi innenfor et kjent område uten at vi vet verdien på forhånd.

For to terninger:

```python
import random

a = random.randint(1, 6)
b = random.randint(1, 6)

print(a, b)
print("Sum:", a + b)

if a == b:
    print("Dobbel!")
```

På spørsmålet om hva vi kan vite på forhånd: resultatet er ukjent, men det skal være et heltall fra 1 til og med 6.

## 07 – for-løkker

**Mål:** Eleven bruker en løkke når samme type handling skal gjentas et bestemt antall ganger.

Telle seksere:

```python
import random

seksere = 0

for _ in range(10):
    kast = random.randint(1, 6)
    print(kast)

    if kast == 6:
        seksere = seksere + 1

print("Seksere:", seksere)
```

Det er ikke nødvendig å forklare `_` inngående. «Vi trenger ikke bruke rundens nummer akkurat her» holder.

## 08 – Gjett tallet

**Mål:** Eleven kombinerer variabler, input, tall, tilfeldighet og betingelser i et lite spill.

Et mulig hintsystem:

```python
import random

hemmelig = random.randint(1, 20)
gjett = int(input("Gjett 1–20: "))

if gjett == hemmelig:
    print("Riktig!")
elif gjett < hemmelig:
    print("For lavt!")
else:
    print("For høyt!")
```

Ikke løs problemet med flere forsøk ved å introdusere `while` på forskudd hvis eleven ikke selv spør. Leksjon 9 er laget for akkurat det behovet.

## Tegn på at eleven er klar for leksjon 9

Eleven kan med støtte:

- skrive en enkel `if/else`
- forklare forskjellen på `=` og `==`
- bruke et tilfeldig heltall
- bruke en `for`-løkke til kjent antall repetisjoner
- kombinere flere tidligere konsepter i et lite program
- forstå hvorfor gjetteleken nå trenger en ny type løkke for å gi flere forsøk
