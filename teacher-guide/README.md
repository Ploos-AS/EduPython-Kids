# Lærer- og foreldreguide

EduPython Kids er laget slik at en voksen ikke trenger å være Python-ekspert for å følge barnet gjennom kurset.

## Grunntanke

Barnet skal lage noe først og få forklaringen etterpå.

Unngå lange foredrag om syntaks. Bruk heller spørsmål som:

- Hva tror du skjer hvis vi endrer dette tallet?
- Kan vi få programmet til å gjøre noe morsommere?
- Hva forteller feilmeldingen oss?
- Kan du finne én ting du vil endre selv?

## En typisk økt

En økt på 30–60 minutter kan se slik ut:

1. Les oppdraget sammen.
2. La barnet skrive eller endre koden.
3. Kjør programmet tidlig.
4. La barnet eksperimentere.
5. Bruk Bug-jakt hvis dere vil øve på feilsøking.
6. Avslutt med utfordringen dersom barnet fortsatt er motivert.

Det er ikke nødvendig å fullføre alt hver gang.

## Om feil

Ikke rett alle feil med én gang. Hjelp barnet med å lese feilmeldingen og finne omtrent hvor problemet er.

Målet er at feil skal oppleves som spor, ikke som nederlag.

## Hjelp uten å ta over

Hvis barnet står fast, prøv denne rekkefølgen:

1. Be barnet forklare hva programmet skulle gjøre.
2. Se på siste linje i feilmeldingen.
3. Finn linjen Python peker på.
4. Sammenlign med eksempelet.
5. Gi et lite hint før du viser løsningen.

## Miljø

En vanlig Python 3-installasjon er nok for de første leksjonene. Senere Turtle-leksjoner krever Tk-støtte.

Kurset skal også kunne brukes offline.
