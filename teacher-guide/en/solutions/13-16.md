# Adult notes and solution guidance – lessons 13–16

This stage is increasingly about creating rather than copying. Avoid making every learner project identical through overly detailed solutions.

## 13 – Lists
**Goal:** Understand that one variable can contain a collection and that code can visit its values.

```python
import random
items = ["map", "key", "apple"]
print(random.choice(items))
```

An out-of-range index is a useful opportunity to show that three items have indexes 0, 1 and 2.

## 14 – Turtle
**Goal:** Connect loops, functions and simple geometry to a visible result.

```python
def polygon(sides, length):
    angle = 360 / sides
    for _ in range(sides):
        pen.forward(length)
        pen.right(angle)
```

Precise geometry terminology is not the goal. Let the learner experiment. Turtle requires a working graphical Python/Tk environment and should be tested before teaching.

## 15 – Robot Monster
**Goal:** Split a drawing into smaller parts and reuse functions.

There is no correct monster design. Look for decomposition, at least one reused function, an ability to explain pen movement and learner-created details. Help with coordinates if necessary without taking over the design.

## 16 – Final project
**Goal:** Complete a simple development cycle: idea → small version → test → improve → demonstrate.

Do not judge the project by how advanced it looks. A small project the learner understands is more valuable than a large one they cannot explain. Help reduce scope when needed.

## When the learner is stuck
Ask: What is the smallest part we can make work? What already works? What value does this variable have? Can we print it? Can we test the function alone? What does the error say?

## After Course 1
A good outcome is not memorised syntax. The learner should be willing to experiment, read and modify small programs, recognise basic control flow, split problems into parts, test ideas, use errors as information and explain their own project.
