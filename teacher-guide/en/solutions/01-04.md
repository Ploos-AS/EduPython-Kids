# Adult notes and solution guidance – lessons 1–4

These notes support adults; they are not an answer key the learner must copy. Several solutions may be correct.

## 01 – Hello, Python!
**Goal:** The learner understands that a program contains instructions and can change text in `print()`.

For `"3 + 4"` versus `3 + 4`, help the learner notice that quotation marks make text, while numbers without quotes are calculated. There is no need for advanced terminology yet.

## 02 – The program remembers
**Goal:** The learner can store and change values in variables.

```python
animal = "cat"
animal = "dog"
print(animal)
```

The result is `dog`. A label or box metaphor can help, but make clear that the variable does not automatically remember all previous values.

## 03 – Talk to the computer
**Goal:** The learner connects a question, its answer and a variable.

```python
animal = input("Favourite animal: ")
colour = input("Favourite colour: ")
hero = input("Superhero name: ")
print("You chose", animal, colour, hero)
```

Do not require a real full name, address, school or other personal information. Fictional information works just as well.

## 04 – Numbers and mini calculator
**Goal:** The learner discovers the difference between text and numbers and can use `int()`.

```python
a = int(input("Number 1: "))
b = int(input("Number 2: "))
print("Sum:", a + b)
print("Difference:", a - b)
print("Product:", a * b)
```

`"2" + "3"` becomes `"23"`, while `2 + 3` becomes `5`. If `int()` receives unsuitable text, use the error as debugging practice; do not introduce `try/except` yet.

## Ready for lesson 5
With some support, the learner can run and change a small program, use `print()`, create/change a variable, receive input, convert suitable input with `int()`, and read the final part of a simple error message.
