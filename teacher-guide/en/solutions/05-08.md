# Adult notes and solution guidance – lessons 5–8

The goal is understanding and explanation, not merely producing correct code.

## 05 – if
**Goal:** Understand that a program can choose which code runs.

```python
word = input("Secret word: ")
if word == "python":
    print("You may enter!")
else:
    print("Try again later.")
```

Useful errors to investigate include `=` instead of `==`, a missing colon and wrong indentation. For `elif`, drawing three possible paths on paper can help.

## 06 – Randomness
**Goal:** Understand that a program can choose within a known range even when the exact result is unknown.

```python
import random
a = random.randint(1, 6)
b = random.randint(1, 6)
print(a, b)
print("Sum:", a + b)
if a == b:
    print("Double!")
```

The exact roll is unknown beforehand, but its possible integer values are known.

## 07 – for loops
**Goal:** Use a loop when an action repeats a known number of times.

```python
import random
sixes = 0
for _ in range(10):
    roll = random.randint(1, 6)
    print(roll)
    if roll == 6:
        sixes = sixes + 1
print("Sixes:", sixes)
```

There is no need for a detailed explanation of `_`; “we do not need the round number here” is enough.

## 08 – Guess the number
**Goal:** Combine variables, input, numbers, randomness and conditions.

Do not solve repeated guessing by teaching `while` early unless the learner asks. Lesson 9 is designed to answer that need.

Useful prompts: What do you predict? Which line decides this? What can we safely change? How could we test this better?

## Ready for lesson 9
With support, the learner can write a simple `if/else`, distinguish `=` and `==`, use a random integer, repeat with `for`, and combine earlier concepts in a small program.
