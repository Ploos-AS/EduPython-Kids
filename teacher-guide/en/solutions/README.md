# Adult notes and solution guidance

These notes support adults guiding Python Explorer. They are not an answer key for learners to copy.

The Norwegian edition currently contains the detailed lesson-group notes. English detailed notes are being completed in the same four groups:

- Lessons 1–4
- Lessons 5–8
- Lessons 9–12
- Lessons 13–16

Use questions and small hints before showing solution code. More than one solution may be correct, especially in later lessons.

The goal is for learners to explain choices, test ideas and find bugs — not to make their program identical to an example.
