# Adult notes and solution guidance – lessons 9–12

Learners now move from isolated concepts toward state, repetition and reusable code. Allow more than one valid solution.

## 09 – while
**Goal:** Understand the difference between “repeat a known number of times” and “continue while something is true”.

```python
number = 5
while number > 0:
    print(number)
    number = number - 1
print("START!")
```

For code-word exercises, use fictional course words, never real passwords. If a loop never changes the value affecting its condition, let the learner investigate why it cannot stop.

## 10 – More attempts
**Goal:** Combine `while`, `if`, input and game state.

```python
attempts = 0
found = False
while attempts < 5 and not found:
    guess = int(input("Guess: "))
    attempts += 1
    if guess == secret:
        found = True
```

Other solutions, including `break`, can also be valid. Discuss differences without presenting one style as the only correct one.

## 11 – Functions
**Goal:** See a function as a named task that can be reused.

```python
import random
def roll(sides):
    return random.randint(1, sides)
```

Distinguish displaying a result with `print()` from returning a value that other code can use.

## 12 – Monster Battle
**Goal:** Begin thinking like a game designer rather than only filling in code.

There is deliberately no complete design answer. Look for a runnable game, explainable rules, reactions to player actions, reuse of earlier concepts, and evidence of testing and improvement. When health or damage values change, discuss balance and how rules affect play.

## Debugging
Ask what last worked, which small part can be tested alone, which values could be printed, whether the loop repeats correctly and whether it stops correctly.

## Ready for the next stage
With support, the learner can explain why a `while` loop continues/stops, track simple state, create/call a function, use `return`, combine concepts and adjust a game rule after testing.
