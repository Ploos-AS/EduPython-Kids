# Teacher and parent guide

EduPython Kids is designed so an adult does not need to be a Python expert to guide a learner.

## Core idea

Let the learner make something first and explain it afterwards. Prefer questions such as:

- What do you think happens if we change this number?
- Can we make the program do something more fun?
- What does the error message tell us?
- Can you find one thing you want to change yourself?

## A typical session

1. Read the mission together.
2. Let the learner type or change the code.
3. Run the program early.
4. Let the learner experiment.
5. Use Bug hunt for debugging practice.
6. Try the challenge while motivation is still good.

It is not necessary to finish everything every time.

## Helping without taking over

Ask what the program should do, read the final error line, find the indicated source line, compare with the working example, and give a small hint before showing a solution.

Errors should feel like clues, not defeat. Avoid taking over the keyboard unless the learner asks or an accessibility need makes it useful.

## Environment

A normal Python 3 installation is enough for the early lessons. Turtle lessons require Tk support. The course is designed to work offline.
