# Teacher / parent checklist

You do not need to be an experienced programmer to guide Python Explorer.

## Before the course
- [ ] Python 3 starts on the learner's computer.
- [ ] The learner can create, save and run a `.py` file.
- [ ] `print("Hello!")` works.
- [ ] Turtle works before lesson 14.
- [ ] Course files are available offline.
- [ ] The learner knows where their programs are saved.

## During a lesson
- [ ] Run working code early.
- [ ] Ask for a prediction before running a change.
- [ ] Encourage changing names, numbers and messages.
- [ ] Let the learner read an error before giving the answer.
- [ ] Give hints before complete solutions.
- [ ] Stop while programming is still enjoyable rather than forcing completion.

## When something breaks
Ask: What does the error say? Which line does it mention? What changed? Are parentheses and quotes paired? Is a colon missing? Is indentation correct?

## Completion
Success does not require memorising syntax. The learner should be able to experiment, debug with some guidance and create a small program of their own.

Review the [accessibility guidance](../../docs/ACCESSIBILITY.md) before class where relevant.
