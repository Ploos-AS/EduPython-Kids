# Installasjon og klasseromsoppsett

EduPython Kids er offline-first og krever ingen konto eller skytjeneste.

## Anbefalt nybegynneroppsett
Bruk en aktuell Python 3-installasjon og en enkel Python-editor. Eleven bør ha en tydelig **Kjør**-knapp eller en like enkel måte å starte programmet på. Kurset har ingen tredjeparts Python-avhengigheter.

## Windows
Installer Python 3 fra den offisielle Python-distribusjonen eller bruk skolens administrerte installasjon. Lag en mappe som heter `EduPython`, lagre oppgavene som `.py`, og test med `print("Hei!")`.

## macOS
Installer et aktuelt Python 3-miljø egnet for læring. Ikke baser kurset på en gammel system-Python.

## Linux
Python 3 finnes vanligvis i pakkesystemet. Turtle trenger også Tk-støtte, som enkelte distribusjoner pakker separat.

```bash
python3 --version
python3 -c "print('Hei!')"
```

## Raspberry Pi
Raspberry Pi OS med Python 3 passer godt. Course 1 krever ikke GPIO eller annen maskinvare.

## Turtle-test
Kjør `python3 -m turtle`. Hvis et grafikkvindu åpnes, er Turtle klart. Hvis ikke, kontroller Tk/Tkinter.

## Offline
Klon eller last ned repoet én gang. Markdown-leksjoner og Python-eksempler kan deretter brukes uten Internett.

## Klasserom
Forbered og test maskinene før første økt. Første elevøkt bør starte med programmering, ikke kontooppretting eller feilsøking av installasjonen.
