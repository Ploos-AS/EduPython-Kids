# Learning progression

EduPython Kids Course 1 is designed as a gradual transition from immediate output to independent creation.

| Stage | Lessons | Main ideas | Student outcome |
|---|---:|---|---|
| Discover | 1–4 | output, variables, input, numbers | Can change and run simple interactive programs |
| Decide | 5–8 | conditions, randomness, for loops | Can make simple rules and a small game |
| Build | 9–12 | while loops, functions, game state | Can combine concepts into a multi-step program |
| Create | 13–16 | lists, graphics, decomposition, project work | Can plan, build, test and present a small project |

## Teaching constraints

- Introduce at most one or two major new ideas per lesson.
- Produce a visible or interactive result early.
- Prefer working code before lengthy theory.
- Revisit earlier concepts in later projects.
- Treat errors as normal debugging information.
- Keep Course 1 standard-library-only.
- Do not require accounts, cloud services or proprietary platforms.

## Expected outcome

A learner completing Course 1 should be able to read and modify small Python programs, use variables and basic control flow, create simple functions and lists, interpret basic error messages, and independently develop a small text or Turtle project with guidance when needed.
