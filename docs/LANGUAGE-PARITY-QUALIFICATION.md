# Language parity qualification

**Review date:** 2026-09-25  
**Scope:** Python Explorer Course 1 student and adult-facing material  
**Status:** PASS WITH CONTINUOUS REVIEW

## Policy

Norwegian remains the primary authoring language. Norwegian and English are equal first-class supported editions. Parity means equivalent learning goals, progression, difficulty, privacy/safety principles and teaching rhythm; it does not require literal translation.

## Evidence reviewed

- 16 Norwegian and 16 English teaching lessons
- 16 Norwegian and 16 English exercise files
- student checklists in both languages
- four printable lesson groups in both languages
- core teacher/parent guidance in both languages
- pacing and final-project guidance in both languages
- four adult solution-note groups in both languages
- learner-facing installation, progression, offline and accessibility guidance
- automated structural parity checks in CI
- bilingual offline-bundle coverage

## Human content review

Lessons 1–4 received an additional parity pass because the first English drafts were shorter than the Norwegian canonical material. Lessons 2–4 were expanded with debugging, prediction, exercises, recap and forward progression. Lessons 5 onward were authored from the established Norwegian lesson structure and retain the recurring hands-on model.

This review establishes pedagogical parity, not sentence-by-sentence identity.

## Result

**Course 1 language parity: PASS WITH CONTINUOUS REVIEW.**

Future student-facing changes must preserve both editions before the relevant milestone is considered language-complete. Automated checks protect structure; human review remains necessary for natural language and teaching quality.

This result does not change the separate M2 Turtle/Tk requirement. M2 remains pending until the real graphical Q1–Q6 qualification is completed.
