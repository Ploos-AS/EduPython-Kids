# Printable Python Explorer sheets

These files are compact, print-friendly companions to the canonical Norwegian lessons.

They are **not a second version of the course**. The full lesson remains the source of teaching content. A printable sheet gives the learner room to predict, change, test and write short notes while working through the lesson.

## How to use them

1. Open the matching lesson in `course/no/`.
2. Give the learner the matching sheet.
3. Let the learner write predictions before running code.
4. Use the sheet for notes, bug hunting and reflection.
5. Keep unfinished challenges for another session rather than rushing.

## Print format

The sheets deliberately use plain Markdown:

- no colour is required
- no web connection is required
- no QR code is required
- checkboxes work on paper
- code is kept in the canonical lesson rather than duplicated here
- fictional information is preferred when personal information is unnecessary
